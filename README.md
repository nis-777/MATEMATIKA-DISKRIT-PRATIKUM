## DESKRIPSI

Praktikum ini membahas penerapan logika Boolean dalam
pemrograman Python. Setiap program dibuat berdasarkan
kondisi tertentu untuk menghasilkan keputusan sesuai
dengan aturan yang telah ditentukan.

## REPOSITORY

Repository ini digunakan untuk menyimpan seluruh program
dan hasil pengerjaan Praktikum Matematika Diskrit Modul 1.
Program yang dibuat menerapkan konsep logika Boolean
dalam berbagai permasalahan.
